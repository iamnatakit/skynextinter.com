# Header design assets

- `skynext-logo.png`: original transparent logo supplied by the user through
  https://chatgpt.com/s/m_6ad3f71f271881919d162009e1eedf76 . Copied without editing.
- `rice-hero.png`: generated with the built-in ImageGen tool using the user's
  attached header screenshot as the edit reference. Navigation, text and buttons
  are separate HTML elements; they are not baked into the background.

Final prompt used for the hero background:

> Edit target: attached website screenshot. Produce ONLY the clean background
> photograph for a full-width website hero, landscape 16:9 or wider high resolution.
> Remove ALL text, logo, navigation, icons, buttons and white cards. Faithfully
> reconstruct the scenery behind them: lush golden ripe rice stalks in the
> foreground, expansive sunlit Thai rice fields, distant green hills, morning mist,
> sunrise from the upper left, bright soft blue sky and scattered glowing clouds.
> Preserve the same composition, photographic realism, warm golden and fresh green
> palette and horizon height of the reference. No typography, no branding, no UI,
> no frames. Save output image as a project asset; return the output path.
